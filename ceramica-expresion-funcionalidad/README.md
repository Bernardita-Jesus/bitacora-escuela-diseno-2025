## solemne replicas

### esculpido y ahuecado

para las solemenes estubimos trabajando con replicas, hacer replicas a escala de piezas, primero esculpimos a mano un objeto organico el cual tenemiamos que escoger, yo escogi una piedra con conchitas las cuales eran pequeñas en tonces la replica fue en mayores dimenciones, luego tuvimos que ir esculpiendo y tallando para conseguir las formas y texturas.

una vez lista la forma con la tecnica de ahuecado cortamos las piezas y las vaciamos, ya que pueden secarse por completom piezas rellenas de arcilla y eso es un riezgo ya que en el horno puede explotar.

### moldes de yeso y placas

luego tuvimos que escoger una pieza que sea simetrica, idealmente con eje de simetria pero solo encontramos una botella con aspersor, para este ejercicio ibamos a hacer moldes de yeso para con laminas de arcilla, placas, ibamos a replicarlos con este molde.
